The order of operations

The order matters. Each step below is something I did, in the order I did it.

  1. Install offline, with a local account

    No Ethernet and no Wi-Fi during setup. The whole install took about 12 minutes. Setting up with a local account avoids the Microsoft account prompt.

  2. Turn off Windows Update immediately

    Done before the PC ever touches the internet. Connecting first lets Windows pull down updates. Note: can't stop it from installing pre installed apps.

  3. Connect Ethernet

    Only after the update service was already off. This was the first time the machine went online.

  4. Run Chris Titus Tech WinUtil, then restart

    I used Chris Titus Tech's WinUtil and picked only the tweaks I was comfortable with, then restarted.

  5. Run Win11Debloat, then restart

    I used Raphi's Win11Debloat with only the options I was comfortable with, then restarted again.

  6. Disable the services

    Done manually in services.msc. The full list and reasons are in the Services section below.

  7. Disable the scheduled tasks

    Done in Task Scheduler. Disabling a service doesn't stop the scheduled tasks that feed the same data collection, so these are handled separately.

  8. Block the delivery and telemetry addresses

    Windows Defender Firewall with Advanced Security, using outbound rules. Details in the Network section.

Check your version with ver in Command Prompt. Mine reports Microsoft Windows [Version 10.0.26100.1742].

If a service won't stay disabled

Some services can't be changed from services.msc alone or they switch back after a restart. Open Registry Editor (search for regedit) and go to HKEY_LOCAL_MACHINE, SYSTEM, CurrentControlSet, Services. Every service has its own key there, named after its service name, not its display name. Open the key, find the Start value and set it to 4 to disable, 3 for Manual or 2 for Automatic. Export the key first so you can restore it.

Network addresses observed

Windows Defender Firewall can't block by name, so these are IP addresses. The Microsoft delivery addresses can change. Three addresses are blocked; two other observations are pending identification or optional. They were found using a custom live network traffic tool I built with Rust.

How the rule is set up

Create an outbound rule in Windows Defender Firewall with Advanced Security. Choose Custom, use All programs, select TCP with remote ports 80 and 443, then under Scope add the addresses above. Choose Block the connection and apply it to Domain, Private and Public. Make a second rule for UDP if you want the same block there.

Tradeoffs and things to check

Everything above is a choice with a cost. Read these before copying any of it.

No security patches

With Windows Update off, fixes for newly discovered vulnerabilities don't arrive. Turn it back on for a while when a serious Windows problem is in the news, then turn it off again.

Defender is still running

Its definition updates are blocked by the addresses above, so signatures will age. Check Protection updates in Windows Security to see the block working.

Restore point first

Create one before each script and each batch of service or task changes. Export registry keys before editing them so the changes can be reversed.

Addresses drift

Microsoft's delivery addresses are shared across CDN ranges. Use whatever tool is at your disposal to check them periodically.

Changes don't stay put

Feature updates can re enable services and tasks. A quick pass through this page after any major update catches them.
